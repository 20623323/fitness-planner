# Fitness Planner

A simple fitness planning and tracking web application built using React.

## Features

- Add and manage workout plans
- Specify workout day, exercises, sets, reps, and duration
- Mark workouts as completed
- Delete workouts
- Dashboard showing:
  - Planned workouts
  - Completed workouts
  - Remaining workouts
  - Completion percentage
- Weekly progress bar
- Nutrition tracker for:
  - Calories
  - Protein
  - Carbohydrates
  - Fats
- Workout data is saved using browser localStorage
- Responsive design for desktop and mobile screens

## Technologies Used

- HTML
